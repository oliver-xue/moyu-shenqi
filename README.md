# 摸鱼神器

一个原生微信小程序，用于根据月薪、班次、休息段和当月工作日计算「当日已赚金额」。应用数据保存在本地存储中，不依赖后端、登录或网络请求。

## 功能

- 5 步引导设置月薪、班次、休息段和单/双休制度
- 首页实时展示已赚金额、下班倒计时和当前状态
- 新增四种班次选择：标准班、固定周班、轮班制和手动排班，适应标准作息、固定每周值班、做休循环和特殊排班人群
- 支持跨天夜班、休息中金额冻结、下班收益封顶和可选加班计时
- 根据内置 2026 年法定节假日与调休数据计算当月工作日
- 提供计算依据说明和本地正计时记录

## 本地验证

项目不需要安装 npm 依赖。

```bash
npm test
```

该命令会依次运行计算逻辑测试和小程序源码静态校验。

## 导入微信开发者工具

1. 安装并打开[微信开发者工具](https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html)。
2. 选择「导入项目」，目录指向本仓库的 `miniprogram/`。
3. 仓库中的 `appid` 已使用占位值 `touristappid`。导入时填入你自己的小程序 AppID，或选择「测试号」。
4. 点击「编译」预览。

如果你想清空本地数据并重新查看引导页，可进入「设置 → 重新设置薪资与班次」。
