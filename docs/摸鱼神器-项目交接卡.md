## 3. 固定口径（不要回退）

- **薪资基准月** = 填写时的上一自然月，**只标注这份月薪的来源，不进入任何公式**。
- **计算基准月** = 当前自然月（本月）。`D` = 本月**整月**工作日数（周一至周五 − 法定放假 + 调休补班），非累计到今天。
- `时薪 = 月薪 / D / (T/3600)`；`T =（下班 − 上班）− 休息段`；`日薪 = 月薪 / D`（与 T 无关）。
- **显示符号用 D / T**；但**代码变量 `d.N`、`d.S`、`T`（time 工具别名）保持原样**——`T` 已被时间模块占用，改局部变量会冲突。
- 加班不引入倍率，收益在下班时刻封顶；休息中金额冻结、墙钟倒计时继续；金额每 tick 用绝对时间戳**全量重算**，不逐秒累加。
- 跨月：薪资数值沿用旧值并提示更新，但 D 每月 1 日自动按新月重算，时薪 / 日薪随之变化。
- 2026 节假日依据国务院办公厅 2025-11-04 通知，内置于 `utils/holidays.js`：2026-10 = 18 天、11 = 21 天、12 = 23 天；缺年份降级周一至周五。
